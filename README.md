# ระบบติดตามข้อเสนอแนะ PM2.5

หน้าเว็บ: index.html / pm2_5.html
หน้าเข้าสู่ระบบ: login.html
หน้าจัดการ: admin.html

ใช้ Supabase โครงการ envihub-learning โดยแยกตาราง pm25_admins และ pm25_content และบังคับสิทธิ์ด้วย RLS ผู้ดูแลใช้บัญชีที่ได้รับสิทธิ์เดิมของโครงการ
